The original project

Discord Quest Completer

by Mark Terence Tiglao (@markterence)

Questly started as a fork of Discord Quest Completer. The core idea, starting a small stand-in program with a game's executable name so Discord detects it, comes from there, along with the original Tauri app, the stand-in programs for each platform, and the daily mirror of Discord's detectable game list that Questly still downloads. It's released under the MIT License, which is why Questly can build on it, and why its copyright notice travels with Questly's code.

See the original on GitHub Support the original author

What Questly adds

A redesigned interface with themes and a custom theme editor, an installer and launcher in one file, Spotlight search, timed runs that wait for Discord's detection, square game windows, Performance Guard, Panic Abort, Legitimate Buddy, Launch on startup, an accent-colored app icon, a startup animation, and library import and export. Questly is made by svyixiu.

Built with

  • Tauri and Rust for the app itself
  • Vue.js, VueUse and Tailwind CSS for the interface
  • Fuse.js for search
  • discord-sdk by Embark Studios for the RPC test
  • Archivo by Omnibus-Type for the type
  • Vite to build the app and this website

Full license details are on the Licenses page.

Data

Game names, executables and icons come from Discord's public list of detectable applications and its image server. They belong to their owners and are only shown to identify games.
