Things to try
  1. Press Ctrl K and add a game.
  2. Press Play and watch Discord "detect" it a few seconds later.
  3. Start a timed run with Ctrl T, then switch on Heavy CPU load.
  4. Settings → Accent: the taskbar icon changes too.
  5. Turn on Legitimate Buddy in Settings, then switch on I'm away.
  6. Ctrl Shift X is Panic Abort.
